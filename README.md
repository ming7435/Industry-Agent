# Industry-Agent

面向工业机器的智能诊断系统

## 项目说明

Industry-Agent 是一个面向工业设备运维、故障诊断和生产零件质检的 Multi-Agent 平台。系统通过监控、知识检索、CAD 工程数据和维修工单协作，形成从异常发现到维修闭环的智能化流程。

## 核心链路

```text
设备监控 → 异常确认 → 智能诊断 → 知识检索 / CAD 查询
→ 维修计划 → 工单执行 → 维修验证 → 经验沉淀与报告
```
