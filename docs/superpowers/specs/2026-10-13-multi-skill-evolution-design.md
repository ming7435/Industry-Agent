# 多类技能优化设计

## 目标与范围

用户要求技能优化不局限于智能诊断。沿用现有独立 Skill Loop 和人工审核→验证→发布流程，不改变 Agent Loop 的业务循环。

本次支持诊断类技能、知识检索类技能及 CAD 的 production_modeling_skill。诊断沿用模拟机器验证；知识检索增加有界、只读的技能驱动检索排序；CAD 使用已有严格规格解析流程验证候选，不执行 FreeCAD、生产或机器控制。其余固定算法技能仍可人工维护，但不能宣称改 Markdown 会自动改变算法。

## 决策与数据

- 用统一能力表确定自动优化和验证模式，不再硬编码只允许 diagnosis。
- 同一技能必须有完整周窗口、实际指纹匹配的业务问题才可入选；无观察和基础设施错误不生成候选。
- 每周全局预算仍为 3，保留持久 CAS、在途稿互斥和不确定写入不重试。
- 知识模型只重排已有检索操作，不能增加/删除工具、改变设备、报警、过滤条件、调用预算或证据标准；失败退回既有顺序。
- CAD 技能只影响模型解析与补充问题；确定性解析和严格尺寸、安全检查不降低。候选验证必须实际触发正文，不以固定解析结果冒充模型技能验证。

## 验证契约

任务样例由人工提交，包含实际问题、参考资料或预期规格及结构化预期状态。服务器执行真实被测 Agent/解析函数，模型只作为外部依赖替身用于回归测试；运行时使用现有 Model 服务。

服务端生成只读验收记录，绑定本人、草稿指纹、依赖与基线。知识检索必须验证所选技能被实际消费、证据来自样例、状态与结构化预期一致；CAD 必须验证候选正文被消费、严格规格与人工预期一致，缺尺寸探针不能被补造。测试结果不可由客户端提交 passed=true。

新模式可进入四项北极星统计，展示相应验收项而不是显示不相关的工单和报告。它们不代表实体内核或生产验收通过。

## 兼容与安全

保留现有 machine 请求与诊断验证。候选只追加规则，原权限、步骤、安全、阈值不变。专家中心按能力显示测试输入；不适用的技能明确标注，不显示误导性自动优化状态。已有周计划不得回放收费调用或丢失已占额度。

直接修改当前本地项目，不创建远程任务、部署、不改生产配置。修改前备份源码，不复制密钥；测试使用临时技能目录、隔离存储和模型/工具适配器。
