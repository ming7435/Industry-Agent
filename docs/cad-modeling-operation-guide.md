# FreeCAD 本地三维建模操作说明

当前页面的活动生成链已经从 BuildCAD 切换到本地 FreeCAD MCP。无需 BuildCAD 登录，也不再依赖其远端 `render_preview`。本说明替代旧 BuildCAD 页面操作说明。

## 打开与生成

打开 [生产建模页面](http://127.0.0.1:8001/?view=cad)，确认连接区显示“已连接 · 本地 FreeCAD”。

可以直接点击“填入带通孔销轴示例”，或填写：

```text
外径30mm、长50mm的销轴，带同轴通孔直径10mm
```

点击“生成 3D 模型”。这组完整参数走本地确定性解析，不需要调用收费聊天模型。结果应为一个带同轴贯穿孔的实体，包围尺寸 `30 × 30 × 50 mm`，体积约 `31415.927 mm³`。

也可以点击“填入正四面体示例”，直接填写：

```text
正四面体（立体三角形、四面相同、边长100mm）
```

这不是曲面，而是四个等边三角形围成的平面多面体。已实测生成 4 个面、6 条等长边，体积约 `117851.130 mm³`。将 `100mm` 改为 `120mm` 再生成，会建立新的实体版本，不覆盖原文件；两个尺寸均已通过实际页面和 FreeCAD 内核验证。

当前建模工具支持毫米单位的圆柱、长方体、正四面体及其添加、切除组合；每步必须保持一个有效实体。自然语言的其他描述可由项目已有 Model 服务转换为结构化参数，仍须按完整语义核对，不能只检查数字出现过。长、宽、高、外径、孔径、边长不能相互借用，孔数、孔位、键槽等特征不能被省略。无法完整核对的复杂组合需要人工确认结构化规格。缺少尺寸、方向或出现当前不支持的倒角、螺纹等特征时，不能以一个不完整模型冒充成功。

示例尺寸不是工业设备验收标准。材料、强度、配合公差、表面要求和加工工艺仍需设计人员确认。

## 预览与下载

成功生成后，在同一页面“FreeCAD 建模结果”下方展示实际导出的 STL，而不是图片或前端猜出的替代几何。

- 鼠标拖动：旋转；滚轮：缩放；右键拖动：平移。
- 页面按钮：复位、缩放、自动旋转和全屏。
- “下载 STL”：三角网格文件，用于查看或适用的后续流程。
- “下载 STEP”：真实实体交换文件，可导入其他 CAD 软件。
- “下载 FCStd”：FreeCAD 文档文件，可用 FreeCAD 桌面软件打开。

如果浏览器 WebGL 不可用，页面会说明预览失败，不绘制假模型；已校验的实体文件仍可下载。

## 人工确认与修改在哪里

页面可核对原始需求、模型外观、实体个数和包围尺寸；正四面体还显示四面六边的拓扑校验。修改需求后再次提交会生成新的运行和文件，不覆盖旧版本。

需要在桌面 CAD 中修改时，下载 FCStd，用 FreeCAD 打开。当前导出是固定模板生成的最终实体，**不是包含全部可编辑草图尺寸约束的完整参数化特征树**。可在该实体上继续建特征；若要改变原始尺寸，优先修改页面需求并重新生成。

没有自动生产放行按钮，也没有下发刀路、G-code 或控制设备。几何有效、设计人员确认、机床可加工及允许启动生产是不同的条件。本轮只打通建模、预览、文件导出，不将其标记为工业加工验收。

## 节点、技能、工具

```text
前端 POST /api/cad/freecad/runs
  → CAD Agent
  → model_3d 节点
  → production_modeling_skill（中文 Markdown）
  → freecad_mcp（本地受限工具）
  → freecad-mcp stdio：execute_code
  → FreeCAD GUI 内部 XML-RPC（127.0.0.1:9875）
  → 建实体 / STEP 回读验证 / STL 与 FCStd 导出
  → 前端真实 STL 交互预览
```

页面“执行路径”显示 Agent、节点、Skill、Tool 的名称。“实际工具调用”显示本轮 `execute_code` 的固定模板参数、原始返回体或受控错误；生成执行也进入项目现有 TraceRecorder。

用户和聊天模型只能提交结构化参数，不能通过这个 HTTP 入口提交任意 Python。模板代码由服务器固定生成，工具也不加入通用模型的工具列表。

## 启动与记录

在项目根目录运行：

```powershell
& L:/anaconda/python.exe -u scripts/start_all.py
```

本机开发环境下，启动器会启动或复用已经安装在项目 `.runtime` 内的 FreeCAD。不会下载依赖；安装缺失或启动失败时会明确说明，其他服务继续运行。生产环境不隐式启动桌面 CAD。完整部署说明见 [本地安装与启动](freecad-local-setup.md)。

运行记录存 Redis，默认 24 小时。实际文件在 `.runtime/cad-models/FC-运行编号/` 中，不使用 SQLite，不保存到 BuildCAD。Redis 记录过期后，HTTP 下载入口不再开放该记录，但本地文件不会被自动删除；需要保留的设计应及时下载或按项目长期归档流程保存。

刷新只查询原任务，不重新生成。超时或连接中断时可能显示“结果不确定”，因为 FreeCAD 仍可能在执行；先核对原任务，不连续重复点击。尺寸不足时修改需求并提交新运行。

FreeCAD 软件本身还支持草图约束、拉伸/旋转/扫掠/放样、曲面、装配、TechDraw 二维工程图以及 CAM 等。**这些软件功能不等于当前网页已经全部接入**；当前网页提供实际 STL 三维预览及 STEP/STL/FCStd 导出，不自动生成完整二维加工图、刀路或生产指令。

## 保留的维修 CAD 查询

工单设备图纸、BOM、部件关系、3D 故障定位以及 `/api/cad/resolve` 保留。这些读取既有工程资料，不是第二套生产零件生成器。旧 BuildCAD 的客户端、未挂载路由及测试暂作历史兼容代码保留，但当前页面和正式服务没有挂载其生成入口。

实际验证结果、未完成的历史测试迁移和恢复方法见 [本轮接入报告](freecad-local-integration-report.md)。
