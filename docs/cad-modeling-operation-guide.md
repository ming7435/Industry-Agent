# BuildCAD MCP 建模操作说明

当前 CAD 生成只有一套：**通过 MCP 调用 BuildCAD**。旧本地 CadQuery、STEP/STL 导出、上传解析、刀路及虚拟加工入口已经停用。

## 唯一调用链

```text
生产建模页面 → POST /api/cad/buildcad/runs
→ CAD Agent 的 model_3d 节点
→ production_modeling_skill 的 build_model 步骤
→ buildcad_mcp 工具 → https://buildcad.ai/api/mcp
```

一个节点、一个中文 Markdown Skill、一个 MCP 工具包装器。llmcad 代码是发送给 BuildCAD 的参数，不在本地运行，不是第二套几何引擎。

## 页面怎么用

打开 [生产建模](http://127.0.0.1:8001/?view=cad)。

1. 未连接时完成 BuildCAD 登录授权；已连接时不会重复显示登录按钮。
2. 默认选择“仅生成预览”，在需求框说明形状、尺寸、单位和孔槽特征。
3. 点击“提交给 BuildCAD”，查看真实返回；信息不足时根据具体追问补充。
4. 保存已有设计时，先点“读取我的设计”，选中目标，再选择“保存到已选设计”。保存前会读取最新代码并预览同一份修改；只写入选中的设计。
5. “读取设计代码”用于查看所选设计的远端代码。空列表表示账号暂无设计，空代码表示该设计尚无代码，不等于连接失败。

示例需求：

> 设计一个外径 30 mm、长度 50 mm、中心同轴通孔直径 10 mm 的销轴。

这些是示例尺寸，不是实际生产验收标准。不要填写旧流程的 operations JSON、材料表单、加工参数或虚拟 NC 设置；当前页面没有这些入口。

## 预览、保存与人工修改

- `render_preview` 返回静态预览图；本地只显示工具真正返回的图片。
- `save_design` 更新已有设计，必须有真实 `designId`。当前 MCP 没有创建设计工具，需要先在 BuildCAD 官网准备目标设计。
- 人工交互 3D 编辑、修改和导出在 BuildCAD 官网完成。当前本地页面不承诺 MCP 未提供的上传或 STEP/STL 下载。
- 保存可能公开设计，取决于 BuildCAD 账号与服务规则；提交前核对目标。
- 设计保存不等于加工放行，不启动模拟工厂或真实机器。

## 错误与记录

“已连接”只表示授权和工具发现成功，不表示渲染成功。BuildCAD 若返回 `fetch failed`，页面显示失败的工具及返回体，不在本地生成替代模型、不继续保存。写入结果不确定时先到官网核对，不重复提交。

“实际工具调用”可以展开查看参数、返回体或受控错误码。设计存于 BuildCAD，临时运行记录存于 Redis（24 小时）；刷新页面只回查已有运行。

当前账号及远端服务状态以实际查询为准。上次真实预览验证仍收到远端 `fetch failed`，本次清理不会改变该外部故障。详细修改、测试及恢复方法见 [BuildCAD 接入报告](buildcad-mcp-integration.md)。

## 保留的维修 CAD 功能

工单中的设备图纸、BOM、部件关系、3D 故障定位与 `/api/cad/resolve` 继续保留。这些功能读取既有工程资料，不生成生产零件，不是另一套 CAD 生成逻辑。
