# 3D 建模与虚拟加工操作说明

当前工作台：`http://127.0.0.1:8001/?view=cad`。侧栏入口为“生产建模”。

## 1. 建立实体

填写零件名称、需求、材料及技术要求，然后点击“提交 CAD 建模”。

简单实心圆柱可直接输入：`直径30mm、长度50mm的圆柱`，不需要调用模型解析。材料和技术要求必须由你明确填写。

带孔销轴可点击“填写带孔销轴示例”，或者明确填写以下参数；示例尺寸只用于虚拟功能验收，不是工业加工推荐。

```json
{
  "units": "mm",
  "operations": [
    {"type": "cylinder", "diameter": 30, "length": 50},
    {"type": "cylinder", "diameter": 10, "length": 50, "mode": "cut"}
  ]
}
```

示例按钮不会替你确认材料、技术要求或工艺。要继续虚拟加工，仍须填写这些字段。

上传 STEP 可直接读取实体；DXF 必须额外填写拉伸深度和单位；PDF/图片需明确标注尺寸，模型提取参数后必须人工核对。缺失信息不会生成默认零件。

## 2. 查看、下载与确认

任务显示“模型已生成”后，可旋转 STL 预览，核对尺寸、体积、连续实体和 STEP 回读结果。可以打开中文 PDF，下载 STEP、STL、DXF 和参数文件。

核对后点击“确认当前设计版本”。此按钮只确认设计，不启动加工。

## 3. 生成加工包

确认后，下方显示“加工准备 → 虚拟工厂生产”。支持加工 Z 轴圆柱及同轴、同起点、同长度的通孔套筒；复杂几何仍可建模、下载，但不能直接用本车削执行器加工。

30 × 50 mm、中心通孔 10 mm 的套筒，在隔离测试中使用了以下显式参数：

| 字段 | 虚拟验收输入 |
| --- | ---: |
| 毛坯直径 | 34 mm |
| 毛坯总长度 | 70 mm |
| 独立夹持长度 | 20 mm |
| 前端退刀距离 | 2 mm |
| 每刀径向切深 | 1 mm |
| 主轴转速 | 1200 rpm |
| 每转进给 | 0.1 mm/rev |
| 尺寸公差 | 0.02 mm |
| 外圆刀具号 | 1 |
| 钻具号 | 2 |
| 钻头直径 | 10 mm |

实心圆柱的钻具号、钻头直径留空。这里的数字是测试输入，不适用于真实机床、材料或刀具的选型与安全确认。

点击“生成刀路、校验与虚拟 NC”。成功后显示刀路、校验、NC 正文、加工包摘要和文件下载。每次输入变化都是独立命令，不能沿用旧程序摘要。

## 4. 确认虚拟生产与查看反馈

勾选“我已核对该加工包，确认仅在虚拟工厂执行”，再点击“确认并下发虚拟生产”。只有此步骤提交工厂任务并启动它。

页面查询实际刀位、进度、运行时间和材料体积。完成后显示终态外径、内径、长度；不是固定倒计时，也不会自动将加工完成判为质量放行。

任一设备有故障或产线未运行时不能启动。运行中遇到故障会暂停；故障解除后不自动继续。产线恢复走原工单维修人员确认流程；加工任务再由人工确认继续。

请求响应丢失时显示“结果不确定”，先只读查询对账；系统不会盲目再次发送生产命令。重启中断后也必须重新人工确认。

## 5. 常见拒绝原因

- 未生成或未确认设计：先完成实体校验和设计确认。
- 缺材料或技术要求：补充需求、创建新版本，再确认。
- 毛坯长度不足：须覆盖零件长度加独立夹持长度。
- 钻头与已确认孔径不符：核对孔径和钻具，不以不同孔径替代原设计。
- 未支持几何：本车削执行器不支持偏心孔、螺纹、曲面等；不省略这些特征生成错误程序。
- 工厂接口不可用：检查本地 Factory 4529、Agent 8010、工作台 8001 是否运行；CAD 状态需同时显示内核就绪和虚拟工厂已连接。

所有 NC 标记 `VIRTUAL ONLY - NOT FOR REAL MACHINE`。本功能不接真实 PLC，不包含切断、取件、完整刀具碰撞或工业质量验收。
