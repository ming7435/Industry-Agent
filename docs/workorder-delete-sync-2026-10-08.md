# 工单删除与维修方案同步修复

用户要求：删除工单时，同时从列表移除关联维修方案；维修方案与工单状态需要同步。

## 修复行为

- 维修人员可以删除本人的处理中工单，包括已经填写维修反馈的工单。
- 工单删除标记、当前及历次关联方案的删除标记、删除审计在同一个数据库事务中保存；写入失败全部回滚。保留工单原状态、处理说明和维修验证记录。
- 默认工单列表不显示已删除工单；“查看已删除工单的处理记录”可查看本人保留的处理记录。
- 维修方案读取同时核对 Backend 的持久化删除标记，即使事件存储的投影更新失败，也不会重新显示已删除方案。
- 方案页面以关联工单的现行方案快照和执行状态为准。工单完成、更新方案或删除后，已打开的方案页面立即接收更新，切换页面无需手动刷新。
- 修改后的请求版本阻止旧轮询回包覆盖新状态。方案更换仍按设备、事件、修订及业务范围核对，避免同报警的历史方案混入。
- 删除不产生维修完成或复机凭证，内部故障核对仍读取保留的未完成工单。
